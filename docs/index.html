✨ Feature Highlights

🛠️ Profession Visuals

Instantly identify reagents for all crafting professions. Icons are drawn directly from the game's high-res assets.

📜 Quest Intel

Dynamic icons show whether an item is needed for faction-specific or class-specific quests. Never sell a quest item again.

📐 Scale to Fit

Adjust icon scale from 8px to 64px to perfectly match your UI theme and resolution.

⚡ 3.3.5a Optimized

Specifically tuned for the Ascension client with enhanced ID extraction and event-driven configuration.

🛠️ Technical Implementation

ITPI Ascension represents a massive overhaul of the original logic by Bytespire, rebuilt by Xurkon to solve the unique challenges of the 3.3.5a client.

Core Enhancements

  • Safe Hooking: Uses HookScript instead of prototype overrides, ensuring 100% compatibility with TSM, ElvUI, and other major addons.
  • Link Parsing: Pulls IDs from item strings to ensure icons display even on uncached Auction House items.
  • Hardcoded Paths: Bypasses spell-database lag by using direct Blizzard file paths for icons.

📖 Commands & Usage

Command Description
/itpi Opens the graphical configuration window
/itpi test Displays status info (database count, character detection)
