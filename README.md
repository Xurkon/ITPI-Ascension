A powerful World of Warcraft addon for **Project Ascension (3.3.5a)** that displays profession and quest requirement icons directly onto item tooltips.

## ⚡ At a Glance
- **Instant Recognition**: View profession and quest icons directly on item tooltips.
- **Backported for 3.3.5a**: Optimized specifically for Project Ascension performance.
- **Comprehensive Coverage**: Supports bags, auction house, loot, and more.
- **Customizable**: Adjustable scale (8px to 64px) and robust filtering options.

## 🚀 Key Features

- **Instant Recognition**: Quickly see which items are for Alchemy, Blacksmithing, Engineering, etc.
- **Quest Tracking**: Displays icons for neutral, Alliance, and Horde-specific quest items.
- **Darkmoon Faire Support**: Identifies items exchangeable for Darkmoon Faire tickets.
- **Highly Customizable**: 
  - Adjustable icon sizes (up to 64px).
  - Individual profession filters.
  - Class-specific quest filtering.
- **Broad Tooltip Support**: Works in your bags, loot windows, auction house, world map, and comparison tooltips.

## 🛠️ Ascension Edition (by Xurkon)

This version is an unofficial backport and optimization of **Bytespire's** original addon, specifically tuned for the unique constraints of the 3.3.5a client on Project Ascension by **Xurkon**:
- **Optimized ID Lookup**: Uses robust item link parsing to handle items not yet in your local cache.
- **Performance**: High-speed texture loading using direct file paths.
- **Reliability**: character-specific settings that persist across logins and reloads.

## ⌨️ Commands

| Command | Description |
| :--- | :--- |
| `/itpi` | Open the configuration menu. |
| `/itpi test` | Verify database count and status. |
| `/itpi debug` | Toggle technical debug messages. |

## 📦 Installation

1. Download the [latest release](https://github.com/Xurkon/ITPI-Ascension/releases).
2. Extract the `ItemTooltipProfessionIcons` folder into your `Interface\AddOns` directory.
3. Restart your game or `/reload`.
